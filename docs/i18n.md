# 国际化消息工具

`cn.veryai.arcreactor.i18n.MessageService` 基于 Spring `MessageSource`，由组件扫描自动注册，可以通过构造器注入，也可以直接 `new MessageService()` 使用。无需修改 `application.yaml` 或添加依赖。

```java
import cn.veryai.arcreactor.i18n.MessageService;
import java.util.Locale;

MessageService messages = new MessageService();

messages.getMessage(404, Locale.ENGLISH);                 // Resource not found
messages.getMessage("404", Locale.SIMPLIFIED_CHINESE);   // 资源不存在
messages.getMessage(1000, Locale.ENGLISH, "backup");      // Operation backup completed
messages.getMessage(200);                                // 使用当前 Spring Locale
messages.getMessage("unknown", Locale.ENGLISH);          // unknown
```

- 编号支持 `int` 或非空白字符串；字符串编号也可以使用 `user.not_found` 等业务键。
- 不指定语言或传入 `null` Locale 时，使用 `LocaleContextHolder.getLocale()`。在默认 Spring MVC 请求中，语言来自请求的 `Accept-Language`；非请求线程未设置 Locale 时使用 JVM 默认语言。
- 后台任务需要固定语言时，显式传入 `Locale`。工具本身不修改线程语言或 JVM 默认语言。
- 资源位于 `src/main/resources/i18n/`，使用 UTF-8。中文为 `messages_zh.properties`，英文为 `messages_en.properties`，默认资源 `messages.properties` 使用简体中文。
- Spring 按语言及地区逐级查找；对应翻译缺失或语言不支持时回退到默认中文资源，不回退到服务器系统语言。编号在所有候选资源中均不存在时，返回编号本身。
- 参数使用 Spring 的 `MessageFormat` 规则：`{0}`、`{1}` 对应可变参数；带参数的消息中，字面单引号需要写成两个单引号 `''`。

新增消息时，在各语言文件中添加相同编号。新增语言时添加 `messages_<语言>.properties`，地区变体可使用 `messages_<语言>_<地区>.properties`，例如 `messages_ja.properties` 或 `messages_en_US.properties`。

工具持有自己的 `ResourceBundleMessageSource`，不注册全局 `messageSource` Bean，不修改现有控制器、异常、校验或其他业务代码。现有响应不会自动翻译，业务需要时可主动调用此工具。
